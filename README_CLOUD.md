# CONTENT AGENT: подготовка Codex Cloud

## Назначение

Этот технический слой переносит текущий CONTENT AGENT в чистое Linux-окружение. Смысловые инструкции находятся в `AGENTS.md`, `knowledge/`, `skills/` и `data/`; этот файл их не заменяет.

## Runtime и зависимости

- Linux в Codex Cloud.
- Python 3.12.
- Pillow 12.3.0 из `requirements.txt`.
- Node.js, ImageMagick, Sharp и Chromium текущему переносимому рендереру не нужны.
- Свободные шрифты Oswald Variable и Rubik Variable с кириллицей хранятся в `assets/fonts/` вместе с лицензиями OFL 1.1.

Корень проекта определяется в `scripts/project_paths.py` через положение самого файла. Абсолютный путь домашнего каталога Mac не требуется.

## Setup

В настройках Cloud environment выбрать Python 3.12 и указать setup script:

```bash
bash setup/cloud_setup.sh
```

Проверка среды после setup:

```bash
python3 scripts/cloud_environment_check.py
```

Проверка создаёт тестовые JPG только во временном каталоге, кратко проверяет запись в `output/`, удаляет тестовые файлы и не меняет историю публикаций.

## Запуск агента

Открыть задачу Codex Cloud для этого репозитория и передать короткую команду:

```text
Сделай следующую карусель.
```

Агент должен применять существующие инструкции проекта. Постоянные правила и знания находятся в:

- `AGENTS.md`;
- `knowledge/`;
- `skills/`;
- `data/posts_history.csv`;
- `data/content_hypotheses.csv`.

Результат сохраняется без изменения текущего контракта в `output/YYYY-MM-DD_<topic>/`: слайды 1080×1350, caption, sources, briefs, quality report, `contact_sheet.jpg` и другие предусмотренные текущими правилами файлы.

## Рендер

`scripts/render_utils.py` предоставляет переносимые примитивы Pillow:

- холст 1080×1350;
- встроенные шрифты с кириллицей;
- проверенный RGB JPEG;
- генерацию `contact_sheet.jpg`.

Основанные на macOS шрифтах старые `render_slides.py` лежат только внутри уже готовых публикаций в `output/`. Они сохранены как индивидуальные материалы прошлых запусков и не являются Cloud-рендерером.

## Internet в agent phase

Internet нужен в agent phase для актуального research, проверки дат, цифр, новостей и первичных источников. Публикационные сервисы, Instagram API и Meta API не нужны и не должны разрешаться.

Справка по настройке: [Codex Cloud environments](https://developers.openai.com/codex/cloud/environments) и [internet access](https://developers.openai.com/codex/cloud/internet-access).

Минимальный профиль доступа:

- только чтение по HTTP(S), предпочтительно методы GET, HEAD и OPTIONS;
- официальные сайты государственных органов и регуляторов;
- первичные исследования, научные издатели и базы публикаций;
- официальные newsroom, investor relations и документация компаний;
- авторитетные статистические организации;
- при необходимости — источники, прямо требуемые конкретной темой.

Доступ можно ограничивать allowlist доменов, но универсальный закрытый список заранее невозможен: набор первичных источников меняется вместе с темой. Начинать следует с минимального списка и добавлять только обоснованные домены. Запись на внешние сайты не требуется.

## Что настроить в Codex Cloud

1. Подключить будущий Git-репозиторий как environment.
2. Выбрать Python 3.12.
3. Указать `bash setup/cloud_setup.sh` как setup script.
4. Включить agent internet только для research/fact-check с ограничениями выше.
5. Запустить `python3 scripts/cloud_environment_check.py`.
6. Убедиться, что Cloud-сессии доступен инструмент генерации/редактирования растровых сцен, если конкретная визуальная концепция требует AI-сцены. Pillow полностью закрывает финальную типографику, кириллицу, JPG и contact sheet, но не заменяет генеративный визуальный инструмент.

## Нерешённые решения переноса

- Доступность встроенного image-generation инструмента следует подтвердить отдельным Cloud-тестом. Полную карусель на этом этапе не запускать.
- `output/` сейчас намеренно не исключён из Git и не перемещён. Перед первым commit нужно отдельно решить: хранить готовые публикации в Git, использовать Git LFS либо внешнее хранилище артефактов. Существующие публикации не изменялись.
- На исходном Mac системный `/usr/bin/python3` требует Xcode Command Line Tools. Это локальная проблема Mac; Cloud использует установленный Python 3.12 через setup environment.
- Список разрешённых research-доменов потребуется адаптировать к теме без включения публикационных сервисов.
