# Шрифты рендера

- `Oswald-Variable.ttf` — акцидентный шрифт для тяжёлых и компактных заголовков; вес 200–700.
- `Rubik-Variable.ttf` — основной шрифт для текста и подписей; вес 300–900.

Оба файла взяты из официального репозитория Google Fonts и распространяются по SIL Open Font License 1.1. Тексты лицензий сохранены рядом. Шрифты включены в проект, поэтому рендер не зависит от набора шрифтов операционной системы.
